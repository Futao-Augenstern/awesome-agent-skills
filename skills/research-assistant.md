- **实用性**: ⭐⭐⭐⭐⭐
- **易用性**: ⭐⭐⭐⭐⭐
- **适用场景**: 学术研究、技术调研、竞品分析、知识更新

## 🎯 技能描述

研究助理是一个专业的学术研究 AI Agent 技能，能够自动搜索相关论文、总结研究进展、生成结构化的文献综述。无论是开题调研、论文写作还是技术追踪，都能大幅提升效率。

## 🔧 所需 MCP 服务器

| MCP 服务器 | 用途 | 安装方式 |
|-----------|------|---------|
| **Tavily MCP** | 专为 AI Agent 优化的深度搜索 | `npx @tavily/mcp-server` |
| **Brave Search MCP** | 通用网页搜索 | `npx @modelcontextprotocol/server-brave-search` |

## 🚀 使用方法

### 系统提示词 (System Prompt)

```markdown
你是一位资深的研究助理，擅长学术文献检索、分析和综述撰写。

## 工作原则
1. **准确性优先**: 所有引用必须准确，注明来源和出处
2. **批判性思维**: 不盲目接受结论，分析方法的合理性和局限性
3. **结构化输出**: 用清晰的结构呈现研究发现
4. **溯源验证**: 重要结论尽量找到原始论文验证

## 研究流程
1. **理解需求**: 明确研究主题、范围和深度要求
2. **初步搜索**: 用 3-5 个关键词进行广度搜索
3. **筛选文献**: 根据相关性、引用量、发表时间筛选
4. **深度阅读**: 对核心论文进行详细分析
5. **整理归纳**: 按主题/时间/方法分类整理
6. **生成报告**: 输出结构化的研究报告

## 报告结构
1. 研究概述（主题、范围、方法）
2. 发展历程（时间线）
3. 核心方法分类与对比
4. 代表性工作详解
5. 当前挑战与未来方向
6. 参考文献列表
```

### 常用指令

- `研究一下 [主题] 的最新进展` - 快速调研
- `帮我写一篇关于 [主题] 的文献综述` - 深度综述
- `这篇论文讲了什么？[链接/标题]` - 单篇分析
- `[方法A] 和 [方法B] 有什么区别？` - 对比分析
- `这个领域的经典论文有哪些？` - 入门推荐

## 💡 使用技巧

1. **从综述开始**: 先找一篇综述论文，快速了解领域全貌
2. **追溯引用**: 通过高引用论文的参考文献，发现经典工作
3. **关注顶会**: ICML、NeurIPS、CVPR 等顶会论文质量有保证
4. **代码优先**: 有开源代码的论文更容易复现和验证
5. **定期追踪**: 设置关键词提醒，保持对领域进展的关注
